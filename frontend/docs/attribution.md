# Attribution & Licensing

**→ [`../../docs/attribution.md`](../../docs/attribution.md)**

It is a plain file reference rather than a symlink, since symlinks require Developer Mode
or elevation on Windows and would not survive a clone reliably.

Do not duplicate the notice here — the root file is the single source of truth, per the
monorepo spec's decision to centralize the CC0 / CC BY-SA notice instead of repeating it.
